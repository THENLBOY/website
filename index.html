  • arch on my main

The "distraction free" laptop that im currently writing this on has been my biggest project for a while. Its a compaq presario cq60 that i got at a flee market in mint condition for 7,50 euros.

I messed around with it and had it as a (loud) media server for a while, first running debian then i wanted to get into bsd and put freebsd on it, which was fun and felt nice.

I then tried openbsd, but after a bad install and after learning about drive fragmentation i put void linux on it

I put luks on it aswel, and learned how fstab works the hard way- id describe manually writing fstab modules as "something the joker would make batman do in a sick game."
